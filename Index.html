User Guide

  • Polygon View: Visualizes store delivery areas.
  • Order Map & Thermal: Heatmap of orders. Anomaly Detection highlights failed clusters!
  • Rider Trace & Metrics: Select a rider to see their path, success rate, and total deliveries.
  • ETA Calculator: Click on any order dot in Order Map to see Distance and ETA from Store.
  • Search Address: Type address, hit Enter. Press Esc or Bin icon to clear.
  • Draw Geofence: Create new store polygons smoothly.
  • Delete Store: Enter password (123123) to permanently remove a store.
  • PDF Reports: Export beautiful charts and stats to PDF via Menu.
